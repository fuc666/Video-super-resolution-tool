# Video-super-resolution-tool
基于anime4k的超分工具，支持在线超分bilibili和youtube视频，最高可支持超分到4k，支持批量导入本地视频
## 技术栈与致谢 / Tech Stack & Acknowledgements

本项目使用了以下开源技术 / This project uses the following open-source technologies:
* **[mpv](https://github.com/mpv-player/mpv)**: 免费开源的跨平台媒体播放器，作为底层核心 / Free, open-source, and cross-platform media player.
* **[Anime4K](https://github.com/bloc97/Anime4K)**: 高质量的实时动漫视频超分算法 / A set of high-quality real-time anime upscaling algorithms.
